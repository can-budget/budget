# Установка Can / «Можно» на iPhone

Бесплатный вариант — сборка на Mac, подпись и установка через SideStore. Apple Account для подписи и логин приложения — разные учётные записи. Одна сборка может быть установлена на несколько телефонов; первоначальную настройку и проверку продления нужно выполнить на каждом.

## Сборка

Нужны Xcode 26+ и настроенный HTTPS backend. Создайте игнорируемый `apps/ios/Config/Local.xcconfig`:

```xcconfig
CAN_API_BASE_URL = https:/$()/api.example.com
CAN_API_HOST = api.example.com
```

Вместо `api.example.com` укажите свой сервер в обоих полях. Для IP нужен сертификат с этим IP в SAN; проверку доверия не отключать. Запись `$()` сохраняет `//` в синтаксисе xcconfig.

Из корня репозитория:

```sh
make ios-sideload
```

Результат: `build/ios-sideload/<UTC timestamp>/Can-SideStore.ipa` и отчёт сборки. Общий App Group сохраняется, APNs/Apple sign-in для бесплатной сборки не запрашиваются. Системные имена приложения/extension латинские для регистрации у Apple; русские названия сохранены в локализованных ресурсах.

## Первоначальная установка на каждом телефоне

1. Включить режим разработчика, подключить iPhone к Mac по USB и подтвердить доверие.
2. Установить SideStore по [официальной инструкции](https://docs.sidestore.io/docs/installation/install), включая pairing и доверие сертификату разработчика. Пароль и код Apple вводить только в установщике/SideStore.
3. Установить LocalDevVPN от Coxson Engineering LLC, подключиться к Wi-Fi, разрешить локальную сеть и VPN-конфигурацию.
4. В SideStore войти в выбранный Apple Account и выполнить обновление самого SideStore.
5. Импортировать IPA: My Apps → «+» → выбрать файл. Сохранить CanWidget; при выборе способа регистрации использовать **Keep App Extensions (Register App ID for Each Extension)**.
6. Открыть «Можно» и войти с логином и паролем, созданными оператором backend.

Если вход в SideStore с on-device anisette не работает, свериться с актуальной документацией и выбрать поддерживаемый remote anisette server. Проверенная конфигурация использовала `https://mac-ani.jkcoxson.com` с выключенным On-Device Anisette; доступность стороннего сервера может меняться.

## Продление и обновления

Бесплатная подпись действует семь дней. Для продления новой IPA не требуется: SideStore переподписывает установленные приложения. Генератор команды и ежедневная автоматизация описаны в [IOS_AUTO_REFRESH.md](IOS_AUTO_REFRESH.md). Продление не требует присутствия Mac, но требует подходящей сети и исправного pairing.

Для обновления кода собрать следующую IPA и импортировать её как обновление с прежним Apple Account и сохранённым extension. Не удалять приложение: локально могут находиться ещё не отправленные операции. Backend обновляется отдельно через CI/CD.

## Проверка

После установки проверить вход, общий бюджет на двух устройствах, отправку офлайн-очереди, оба виджета, обновление без удаления данных, ручное продление и запуск по расписанию с заблокированным экраном. Изменение счётчика expiry нужно подтверждать для **SideStore и Can**.

На первом iPhone проверены установка, вход и ручной запуск команды с успешным продлением и отключением VPN без Done. Второй телефон и фоновый запуск остаются отдельными проверками. Нельзя запретить пользователю удалять виджет; частотой обновления управляет WidgetKit.

Платный Ad Hoc путь сохранён: `make ios-doctor`, `make ios-release`, `make ios-install IOS_DEVICE="..."`. Для него нужны платное членство, сертификаты, provisioning profiles и зарегистрированные устройства; к бесплатному варианту эти требования не относятся.
