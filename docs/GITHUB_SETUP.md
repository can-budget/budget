# GitHub presentation

The project uses its existing Can application mark. Sources and upload-ready images:

| Asset | File | Size |
| --- | --- | --- |
| Organization avatar | [`assets/avatar.png`](assets/avatar.png) | 1024 × 1024 |
| Repository social preview | [`assets/social-preview.png`](assets/social-preview.png) | 1280 × 640 |
| Editable logo | [`assets/logo.svg`](assets/logo.svg) | SVG |
| Editable social card | [`assets/social-preview.svg`](assets/social-preview.svg) | SVG |

Upload the avatar in **can-budget organization → Settings → Profile → picture**. Upload the social card in **budget repository → Settings → General → Social preview**. These uploads are separate from placing an image in the README.

На личном профиле GitHub открыть **Customize your pins**, выбрать `can-budget/budget` и сохранить. Ссылка на проект в profile README и закреплённый репозиторий — отдельные элементы оформления.

The public repository has an English README, a Russian README, an MIT license, contribution guidance and a private vulnerability-reporting route. Keep the About description and topics consistent with the implemented native iOS + self-hosted API scope. Do not link a private production API as a public demo.
