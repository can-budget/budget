# Проверки пакета v1.1 — 12 октября 2026

Это отчёт о реально выполненных проверках **документации/эталона**, не акт приёмки приложения. Полный вывод и версии среды: check_results.json.

## Выполнено

Python: 7 unittest-методов PASS. В них 240 контрольных fixtures (224 прежних регрессионных и 16 новых для v1.1), 1000 воспроизводимых сценариев базовых инвариантов, 500 сценариев инвариантов с изменениями срока/остатка, дробление пополнений и проверки некорректных входов.

Swift: эталон calculation_version=2 скомпилирован swiftc в Linux; сравнение с теми же 240 expected projections прошло. В новых fixtures явно проверены ключевые ожидаемые банк/дневной остаток/дни/carry, включая edit target, дату, комбинацию, late expense и отсутствие перезаписи вчерашних условий. Остальная полнота snapshot проверяет межъязыковую согласованность, не независимое доказательство всех правил.

Контракт: YAML/JSON читаются; 246 внутренних ссылок разрешены; 48 схем проверены JSON Schema validator; 23 уникальных HTTP operationId; пути/параметры сопоставлены; корректные и некорректные примеры add_entry/update_sprint проверены; версии расчёта/capacity10/revision payload присутствуют. Это НЕ полная сертификация OpenAPI conformance и НЕ вызовы работающего сервера.

Сборка reading-copy из docs выполнена. В новый пакет не помещены старые действующие спецификации/контракты v1.0.

## Не выполнено — обязанности реализации

SQL ещё не запускался на PostgreSQL; нет проверенной migration/rollback, тестов настоящих транзакций, deadlock/изоляции/ограничений при гонке. API-сервис и APNs worker не реализованы. Нет live authorisation, HTTPS, Apple secrets или реального сервера.

Нет Xcode app build, iOS SDK integration, SwiftData queue, WidgetKit/камера/яркость на устройстве, App Group/Keychain entitlement проверки. Swift Linux parity НЕ доказывает iOS-совместимость UI/SDK.

Не выполнены TestFlight upload/review/установка, измерения сетей Китая, backup/restore, performance/security audits и сценарии AC физических устройств. Готовых собственных макетов/иконки Can нет; включены UX-референсы.

R-01 policy удаления общих данных остаётся release gate. Реальные доступы/инфраструктура/подпись заполняются в M0. Репозиторий GitHub не создан/не опубликован этим пакетом.

## Команды повторной проверки

```sh
python -m pip install -r qa/requirements.txt
make check
make swift-check
make spec
```

Для Swift необходим swiftc; для полноценной разработки iOS — отдельная macOS/Xcode среда. После правок эталона/контракта обновлять fixtures и этот отчёт с реальными результатами, не копировать старый PASS.
